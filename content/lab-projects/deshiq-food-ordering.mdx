## What it does

End-to-end food ordering: product browsing with categories and deals, cart with addons, checkout with delivery address and payment method, order history with PDF invoice download, and a react-admin panel for products, categories, and orders. Auth via Google OAuth, maps via Google Maps, uploads via Cloudinary, English/Urdu i18n.

## How it's built

Two repos: a [Next.js 16 frontend](https://github.com/Mueem-Nahid/food-ordering-site-frontend) (React 19, MUI v7, Redux Toolkit + RTK Query, server-gated admin access) and a [Node/Express backend](https://github.com/Mueem-Nahid/food-ordering-system-backend) (TypeScript, Socket.IO, MongoDB) deployed on Vercel.

## Current state

Frontend is live; backend pairs over its API base URL. Built as a complete vertical slice — auth, payments-adjacent checkout, realtime, and admin — rather than a UI mockup.
