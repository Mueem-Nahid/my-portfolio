## Problem

A delivery operation needed three surfaces in sync: customers placing orders, drivers fulfilling them, and admins overseeing the whole flow — with everyone watching the same live state.

## Approach

Built the order delivery system across user and driver apps (Flutter) plus a web admin panel (Next.js), backed by a Node.js API with Prisma and PostgreSQL.

Live order tracking runs on Google Maps with real-time updates pushed over Pusher.

## Outcome

The platform is in production with real-time tracking across all three surfaces.
